# Finance Flow

Личный финансовый дашборд: честный дневной лимит, расписание доходов и платежей с переносами по выходным и праздникам РК,
распределение денег по поступлениям, подсказки «когда и из чего платить».

## Установка (GitHub Pages)
1. Новый репозиторий, например `finance`.
2. Загрузить содержимое этой папки (вместе с `icons`) через «uploading an existing file» → Commit changes.
3. Settings → Pages → Branch `main`, `/ (root)` → Save.
4. Открыть `https://<логин>.github.io/finance/` в Chrome → ⋮ → «Установить приложение».

## Первый запуск
«Импортировать файл» → `finance-schedule.json` (ваше расписание), затем ввести текущий баланс.

## Обновление
Заменить `index.html` и `sw.js`, в `sw.js` поменять `VERSION`. Данные сохраняются.
